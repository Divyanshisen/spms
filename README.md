# 🎓 Student Profile Management System

A simple web-based application that helps manage student records efficiently. Users can add, view, update, and delete student profiles through an interactive interface.

## 🚀 Features

- Add new student records
- View student information
- Update existing profiles
- Delete student records
- Form validation
- Responsive user interface

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```bash
Student-Profile-Management-System/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/student-profile-management-system.git
```

2. Navigate to the project directory

```bash
cd student-profile-management-system
```

3. Open `index.html` in your browser.

## 📖 Usage

- Enter student details in the form.
- Click **Add Student** to save the record.
- Use **Edit** to modify information.
- Use **Delete** to remove records.
